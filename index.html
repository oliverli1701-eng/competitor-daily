在 Codex 中安装

下载完整 ZIP 并解压，在解压目录准备 Python 环境，再执行：

python -m pip install -r runtime/requirements.txt
python scripts/install.py

在新对话中调用 $competitor-daily。已有安装目录会保留，具体步骤见 安装说明。

在 WorkBuddy 中导入

进入技能页面，选择「添加技能 → 上传技能」，导入完整的发行 ZIP。执行能力以你的 Agent 版本为准；项目提供标准 Skill 文件与 Python 程序。
