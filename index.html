A few things, clearly

你的数据。
你的运行方式。

需要把 API Key 给作者吗？

不需要。你的密钥保存在自己工作目录的 .env，只用于你选择的服务。也可以让 Agent 用现有的检索能力整理研究批次，无需另配 DeepSeek Key。费用始终由你使用的平台与账号计费。

装好以后，就会每天自动更新吗？

安装提供能力。需要每天运行时，再让 Agent 配置其支持的定时任务或系统计划。执行机器、网络、权限和凭证需要可用；关闭桌面应用后的执行能力以具体平台为准。

可以换学院，或者扩展其他检索服务吗？

可以。每个 workspace 有独立清单和品牌配置。程序分开处理文档导入、官方来源、事实核验、历史比较和输出。修改对应模块即可扩展，详见 架构文档。

原来的竞赛日报还在吗？

继续保留。作者运行实例的历史网页和 PDF 按年、月、ISO 周、日期归档。进入历史日报 ↗。演示页面有明确标识，不会把样例内容当作当前可报名的比赛。
