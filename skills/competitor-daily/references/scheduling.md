# 每日更新与部署

安装只提供能力，不创建任何定时任务。用户明确要求每日更新时，再确定时区、执行时间、工作目录和失败通知方式。

- 用户的 Agent 支持定时任务：让它在约定时间读取本 Skill，并在用户 workspace 运行。任务中的路径必须为绝对路径。桌面端关闭后是否会运行，由 Agent 平台的能力决定。
- Windows、macOS 或 Linux 本机：分别使用任务计划程序、launchd 或 systemd/cron。机器需要在执行时开机，Python/依赖可用，凭证与网络可访问。不要声称安装 Skill 就能保证每天运行。
- 用户自己的服务器：使用非交互式命令和限定权限账户，设置工作锁、超时、日志上限和报告保留策略。网站发布、GitHub 推送与检索分开重试，避免同步失败时重复付费检索。

先手动完成一次真实日报，验证官方来源、HTML、PDF和输出路径，再创建计划。时间用明确时区，例如 `Asia/Shanghai`。计划运行失败时保留最后成功的日报并展示实际状态，不把旧日报改成今日日期。

GitHub归档和网站部署均为可选扩展。配置用户自己的账号与密钥；不复用作者的仓库权限或服务器身份，不将 `.env`、原始私有文件、状态证据或日志提交公开仓库。
