# Competitor Daily

[查看最新日报](https://cuiying42.com/competitor/lzucs/)

每天北京时间 08:00 发布后自动归档。目录按年 / 月 / ISO 周（周一至周日）/ 日期组织；跨月周分别归入日报所属月份。

历史日报支持在线阅读和 PDF 下载；PDF 也保存在对应日期目录中。
